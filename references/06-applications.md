# 06 应用规范（12 类触点）

所有示例按 v1.2 规则：MiSans、干净底色、小奈不压字、无像素方块辅助图形。通用骨架见 SKILL.md 第 4 节。

## 1. 网站

- 首页只承载**一个主信息 + 一个主行动**；Hero 用「左文右图」，小奈在右侧独立区域。
- 首屏聚合顺序：Banner → AI 护照 → PBL 实战项目 → 精选活动 → 机会；页脚含横版 Logo 与 nexai.link。
- 深色 Hero（#262626）只放一个主信息与一个主行动；示例数据仅作版式示意，不得当真实数据发布。
- 每个区域只有一个紫色主按钮（高 44px），次要操作用描边按钮；卡片用 1px 边框 + 间距，不用常规阴影（阴影仅浮层、弹窗）。
- 颜色、字体、圆角一律从 `assets/tokens/tokens.css` 取，不在业务代码硬编码。
- 桌面 1440 / 中屏 / 390px 三档检查，移动端不是等比缩小，不能横向溢出。

**设计 Token（`assets/tokens/tokens.css`）**

| 类别 | Token | 值 | 用途 |
|---|---|---|---|
| 颜色 | `--nx-purple` / `--nx-purple-deep` | #6857E7 / #3C237C | 主行动、选中 / 悬停、按下 |
| | `--nx-lavender` / `--nx-mist` | #BBBBFE / #F1F0FD | 深底强调字 / 浅底面板 |
| | `--nx-coral` | #FF604A | 截止、限时、增长（仅一处） |
| | `--nx-ink` / `--nx-gray` | #262626 / #6E6E73 | 标题正文 / 次要文字 |
| | `--nx-surface` / `--nx-white` | #F6F6F8 / #FFFFFF | 页面背景 / 卡片 |
| | `--nx-line` / `--nx-focus` | rgba(0,0,0,.09) / rgba(104,87,231,.3) | 1px 分隔线 / 3px 焦点环 |
| 圆角 | `--nx-radius-control` … `-feature` | 10–12 / 16–18 / 20–24 / 999 | 控件 / 卡片 / 大面板 / 胶囊 |

旧变量名（`--nx-purple-hover`、`--nx-orange`、`--nx-dark-navy` 等）仅作兼容别名，新代码不要再用。

## 2. App

- 顶栏高 58px，Logo 居中；底部 Tab ≤ 5 个；导航抽屉用于移动端。
- 小奈同学是可折叠的 AI 伙伴**面板**：关键动作前需用户确认（「需要你确认后，我才会提交」）。
- App 图标：白底彩色图形标为首选，图形标占画布 60%；深色模式用墨黑底；图标内不放字标、小奈或文字。
- 圆角：控件 10–12，卡片 16–18，大面板 20–24，胶囊 999；触控目标 ≥ 44px；焦点环 3px rgba(104,87,231,.3)。
- 动效：悬停 160–200ms、按下 100ms scale(.97)、布局 240ms；尊重「减少动效」设置，认证流程不用弹跳。

## 3. 小程序

- 自定义导航时，Logo 与标题左对齐并避让右上角胶囊；标题 17px MiSans Semibold。
- 头像用白底彩色图形标；分享卡片 5:4，墨黑或雾紫纯色底，左上反白 / 彩色横版 Logo，小奈在右下独立区。
- 启动页白底居中图形标，品牌露出 ≤ 1.5s，不加广告动画。

## 4. 社交媒体（官方账号）

- 头像：官方主账号用白底彩色图形标（占画布 60%，全平台统一）；小奈人设号 / 社群用雾紫底小奈新版头像（仅品牌组授权账号）。
- 账号名：奈势AI；英文平台：NexAI；子账号：奈势AI·社区。
- 简介三行：① 成就每一位AI创造者　② 一句话说明账号内容　③ nexai.link（不用未确认的排名 / 数据 / 合作方）。
- 版式骨架：Logo 固定左上（深色底用反白）→ 一个标签 + 一个大标题（≤ 16 字，2–3 行）→ 小奈在右侧或右下独立区 → 底部 nexai.link。一张图只讲一件事。
- 模板：`assets/social/*.html`，改字后按 `<meta name="size">` 截图导出。

## 5. 自媒体 · 视频

- 同一套字体（MiSans）、同一套色彩、同一个小奈；表情包用于评论区与社群，严肃话题（投诉、退款、事故通报）不发表情。
- 片头（≤ 2 秒，可省略）：墨黑底，图形标淡入后出现字标；或直接用标题画面开场。
- 片尾（3 秒）：竖版反白 Logo + 口号「一起热爱，一起成长！」+ nexai.link，小奈可在侧边独立区（`video-endcard-1920x1080.html`）。
- 字幕：MiSans Medium，白字 + 柔和黑色描边；竖屏 48–60px、横屏 40–48px；每行 ≤ 16 字、最多 2 行；位于画面 65–75% 高度，避开底部 340px；不用花字、彩虹字。
- 水印：右上角全白横版 Logo，高度 = 画面短边 3.5%，透明度 85%。

**各平台语气**

| 平台 | 语气 | 示例（非官方口号） |
|---|---|---|
| 公众号 | 完整、可信、有方法 | 把「能跑」升级成「能交付」：电影票务智能体的作品集怎么写 |
| 小红书 | 亲切、具体、有步骤，emoji ≤ 3 | 3 步写好你的第一个 Agent 作品集 ✍️ |
| 视频号 / 抖音 | 口语、短句，开头 3 秒给结论 | 48 小时，交付一个能演示的 Agent。 |
| B站 | 真诚、有干货，可有梗不低俗 | 从 0 到能跑再到能交付，一次讲清楚 |
| X / LinkedIn | 简洁专业，中英文分开发，不机翻 | Ship real projects. —— Empower Every AI Builder |

话题标签 ≤ 5；不蹭灾难与敏感热点；数据写来源与日期。

## 6. PPT

用 `奈势AI-PPT模板-v1.2.pptx`（16:9，主题字体 MiSans）的示例页改内容，**不从空白页自己拼**。

| 版式 | 规则 |
|---|---|
| 封面 | 墨黑底 + 反白 Logo + 小奈（右侧独立区） |
| 目录 | 左侧雾紫栏，最多 6 项 |
| 章节 | 奈势紫满版，章节号 + 一句话 |
| 内容 | 左文右图，小奈与文字分栏 |
| 数据 | 一张图 + 一个关键数字 + 来源 |
| 结尾 | 竖版 Logo + 口号 + 使命 + 官网 |

- 边距 0.6 英寸；标题写结论；每页一个结构；正文 ≤ 3 个要点。
- 颜色：标题 30–44pt Bold，正文 16–20pt；图表主色紫，强调 1 处用橙；不用渐变底、艺术字、3D 图表。
- 封面与结尾的口号、使命、官网不删改；对外发送导出 PDF；合作方 Logo 放内容页。

## 7. 印刷物料

统一规则：Logo 左上或居中，官网 nexai.link 必出现，口号与使命原文使用，小奈在独立图片区。

| 物料 | 规格 | 要点 |
|---|---|---|
| 名片 | 90×54mm，出血 2mm，≥ 300g | 文字距裁切线 ≥ 5mm；正面白底彩色横版 Logo，背面墨黑纯色底 + 竖版反白 Logo + 口号 + 官网；可局部 UV Logo |
| 宣传单页 | A4 / A5，出血 3mm，157g 铜版纸 | 正面一个结论，背面 3 个要点 + 二维码；文字区在上、小奈在下方独立色块 |
| 海报 | 2:3（如 60×90cm），出血 3mm | 标题 ≥ 版面宽 8%；时间地点固定底部；小奈在标题下方独立区 |
| 画册 | A4 竖版，封面 250g / 内页 157g | 封面只放竖版 Logo + 使命 + 小奈（分区） |
| 二维码 | ≥ 25×25mm，留白 ≥ 2mm | 白底黑码；码下写用途 |
| 邮件签名 | 纯文本 + 图形标 56×56px | 姓名 / 职位 / 公司 / 电话 / 官网 / 口号；不加格言、表情、动图 |

CMYK 输出并打样（奈势紫与渐变紫超色域）。

## 9. 办公标识

整体以浅灰、白、墨黑为基调，紫色只做点缀，文字全用 MiSans。

- 前台 Logo 墙：浅灰墙面 + 彩色横版立体字 + 使命原文。
- 导视总牌：墨黑底白字，箭头在前，中文 + 英文（如「↑ 会议室 清华 – 中科大 / Meeting 3F-01–06」）。
- 门牌：300×130mm 亚克力 / 铝板，左侧 12mm 奈势紫识别条；主名 MiSans Bold 36–44pt，副名为主名 50%，右下为容纳人数与图形标；深色版（墨黑）可用于玻璃隔断。
