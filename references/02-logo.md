# 02 Logo

Logo =「像素星芒」图形标（12 个圆角方块，紫→橙渐变）+「奈势AI」定制字标。**一律用 `assets/logo/svg/` 官方矢量文件**，不重绘、不重打字、不用位图放大。

## 1. 选哪个版本

| 组合 | 适用 | 文件 |
|---|---|---|
| **横版（首选）** | 绝大多数场景：导航、页脚、文档页眉、名片、PPT | `nexai-logo-horizontal-*` |
| 竖版 | 方形 / 竖长版面：画册封面、海报底部、易拉宝、片尾 | `nexai-logo-vertical-*` |
| 图形标 | App 图标、头像、Favicon、极小尺寸 | `nexai-mark-*` |

选版顺序：横版 → 竖版 → 图形标。图形标单独出现时，同一视野内必须能看到「奈势AI」全称。

## 2. 色彩版本与允许的底色

| 版本 | 文件后缀 | 允许底色 |
|---|---|---|
| 彩色（标准，渐变标 + #262626 字） | `-color` | 白（首选）、#F6F6F8、#F1F0FD |
| 反白（渐变标 + 白字） | `-reverse` | 墨黑 #262626，或照片深色平静区 |
| 全白 | `-white` | 奈势紫 #6857E7、深紫 #3C237C、照片 |
| 单色黑 | `-black` | 仅黑白印刷、盖章、刺绣单色 |

- 彩色版**不**放在奈势紫、薰衣草紫、珊瑚橙等中高饱和底上；
- 渐变图形标**不**放深紫底，深紫底一律用全白版；
- 没有「单色紫」图形标，不要自己做。

**v1.2 起：Logo 背后只允许干净纯色。** 不放菱形网格、像素底纹、渐变纹理；不搭配台阶 / L 形像素方块。

## 3. 比例与安全空间（H = 图形标高度）

| 项目 | 规格 |
|---|---|
| 图形标 | H × H 正方形，12 个圆角方块，填充 #7417FF 25% → #FE6702 |
| 字标高度 | ≈ 0.60 H，与图形标垂直居中 |
| 图形标与字标间距 | ≈ 0.21 H |
| 横版宽高比 | ≈ 3.4 : 1 |
| 最小安全空间 | X = 0.5 H（四周 X 内不放文字、图形、裁切线） |
| 推荐留白 | ≈ 0.9 H |

## 4. 最小尺寸

| 版本 | 屏幕最小 | 印刷最小 | 推荐 |
|---|---|---|---|
| 横版 | 高 24px | 宽 25mm | 产品顶栏 28–32px 高 |
| 竖版 | 高 48px | 宽 15mm | 海报 ≥ 版面宽 20% |
| 图形标 | 16px（Favicon） | 6mm | 头像中占 60–65% |

低于最小尺寸改用图形标；刺绣、丝印、激光雕刻等工艺，图形标 ≥ 10mm 且先打样。

## 5. 在图片上使用

- 放画面平静区域，通常左上角；不要放人脸、文字、高频纹理上；
- 对比不足时加深色渐隐（只用墨黑）或白色底板；
- 深色照片用反白或全白版；
- 加白色底板时底板不描边、不加圆角徽章外壳。

## 6. 错误用法（任何渠道都不允许）

✕ 拉伸或压扁　✕ 旋转、倾斜　✕ 更改颜色　✕ 给字标加渐变（图形标改单色也不行）
✕ 加投影、发光、描边　✕ 调换图形与字标位置　✕ 用其他字体重打「奈势AI」
✕ 彩色 Logo 放紫色或低对比底　✕ 放在复杂图片上　✕ 降低透明度（水印除外）
✕ 加框、加圆形徽章外壳　✕ 被小奈或其他元素压住　✕ 自行拼英文字标
✕（v1.2）放在菱形网格 / 像素底纹上——底纹会和像素星芒「打架」
✕（v1.2）搭配台阶 / L 形像素方块——该辅助图形已停用

英文环境用标准横版 Logo，正文写 NexAI，不另做英文字标。
