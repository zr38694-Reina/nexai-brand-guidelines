## 3. Logo 渐变（仅限 Logo）

**#7417FF** 自 25% 处起，过渡到 **#FE6702**，只存在于 Logo 图形标内部。

✕ 把 #7417FF、#FE6702 当界面或物料的独立颜色
✕ 把 Logo 渐变用于卡片、按钮、背景、文字、装饰图形
✕ 调换渐变方向、改起点、加第三种颜色
✕ 使用 **#F26322**——它不是品牌色，橙色强调一律用 #FF604A

## 4. 用色比例

产品界面：白 / 浅灰约 **55%**，墨黑约 **20%**，奈势紫 **≤ 10%**，浅紫阶约 8%，深紫约 4%，珊瑚橙 **≤ 3–5%**。
营销物料：可把墨黑提升为主背景（≤ 60%），珊瑚橙仍每个版面 ≤ 5% 且只出现一处。

## 6. 印刷

CMYK 为屏幕色换算的**参考值**，PANTONE 专色尚未指定。奈势紫与渐变紫超四色印刷色域，重要物料请由品牌组指定专色并实物打样。

色板文件：`assets/color/nexai-swatches.ase`（Adobe）、`.gpl`（GIMP / Inkscape）、`.json`；网页 token 见 `assets/tokens/tokens.css`。
