# 07 禁用清单（拿不准时逐条核对）

## 1. 辅助图形（v1.2 全停用）

像素方块组成的 L 形 / 台阶形辅助图形、菱形网格（像素场）底纹——**全部停用**，不出现在任何新物料里。像素元素只保留在 Logo 图形标与小奈的犄角 / 袖标 / 口袋图案中。

| ✕ 不要 | ✓ 改用 |
|---|---|
| 角落的 L 形像素角标 | 纯色背景（墨黑 / 奈势紫 / 雾紫 / 白） |
| 台阶形像素方块（任何颜色） | 小奈动作做视觉焦点（放在独立区域） |
| 铺满背景的菱形格纹 | 大标题 + 留白 |

已从素材包、Skill、PPT 模板与全部示例中移除：`pixel-corner`、`pixel-stack`、`pixel-field`。
