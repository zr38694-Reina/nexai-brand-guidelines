# 05 小奈（吉祥物）

小奈是一只穿紫色连帽卫衣的白色独角兽，犄角由橙色像素方块堆叠而成。她自信、靠谱，是 AI 创造者身边的伙伴；在产品里以「小奈同学」的身份陪用户完成任务。

## 1. 形象设定

| 项目 | 设定 |
|---|---|
| 名字 | 小奈（产品内 AI 伙伴：小奈同学） |
| 形象 | 白色黏土质感独角兽 · 紫色连帽卫衣 · 橙色像素犄角 · 紫色眼睛 |
| 性格 | 自信、靠谱、好奇、乐于陪练；说话直接、温和，不过度卖萌 |
| 标志细节 | 像素犄角、袖口 Logo、白色抽绳 + 橙色绳头——任何延展都必须保留 |
| 比例 | 宽 : 高 ≈ 1 : 2.07；头部（含犄角）约占全身 53% |
| 标准姿态 | 正面微侧、双手插兜、自信微笑 |

只用 `assets/mascot/` 官方文件。不拉伸、不改色、不镜像、不去色、不切掉犄角或头部；不放奈势紫底（卫衣会融进背景）；不放在复杂照片上。

## 2. 圆形头像（v1.2 重做）

所有圆形图像里小奈都要**居中并露出完整头部**：犄角顶端、两只耳朵、脸和下巴都在圆内，上下左右留均匀空隙。

| ✓ | ✕ |
|---|---|
| 用 `xiaonai-avatar-circle-lavender@1024.png`（圆形外透明）或 `xiaonai-avatar-square-lavender@1024.png`（供平台裁圆） | 裁掉犄角 / 耳朵；头部偏下、过度放大；把全身塞进圆形 |
| 头像中头部占 60–65%；96 / 56 / 36px 都验证过 | 自己拿标准形象裁圆 |

## 4. 动态表情 · 12 枚

与静态表情一一对应的 GIF：透明背景、无限循环、浅色与深色聊天背景都能直接发。规格 240×240、约 2.75 秒、带字版单个约 200KB，配字同样在小奈下方。文件：`assets/mascot/animated/NN-<名>.gif`。

投稿微信表情开放平台时，带字 / 无字两套只选一套（推荐带字版）。

## 6. 小奈与文字的关系（v1.2 新规则）

**小奈永远不压在文字上，文字也不压在小奈身上。** 先划「文字区」与「小奈区」，两区间距 ≥ 1 个图形标高度。

| 排法 | 适用 | 比例 |
|---|---|---|
| ① 左右分栏 | 横版海报、网页 Banner、PPT 内容页 | 文字左 55–60%，小奈右 40% |
| ② 上下分区 | 竖版海报、手机海报、易拉宝 | 标题在上 1/2，小奈在下，底部留官网条 |
| ③ 独立卡片 | 小版面、社媒方图 | 小奈在独立色块卡片中，与文字卡并列 |

反例：小奈挡住标题或正文（信息读不全）、小奈压住二维码、文字叠在小奈身上。

## 7. 组合与边界

- 与 Logo 同框：间距 ≥ 2X（X = 0.5 H），小奈高度 ≥ 3 倍 Logo 高度；
- 小奈单独出现时，画面角落或配文中必须出现「奈势AI」；
- 表情 / 贴纸可只有小奈，但同一画面要有品牌落款；
- 不出现在认证结论、证书、薪资数据旁暗示担保；不代言合作方；
- 不做「AI 替你完成一切」的姿态——小奈是陪练，关键决定由用户确认。
