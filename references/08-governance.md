# 08 品牌管理：审批 · 命名 · 常见问题 · 版本

规范只有被执行才有意义：从哪里拿素材、谁来审、怎么命名、有问题问谁。

## 1. 流程

① 填需求单 → ② 从官网 / 本仓库下载模板制作 → ③ 对照 SKILL.md 第 6 节清单自检 → ④ 品牌组审核 → ⑤ 打样 / 预览确认 → ⑥ 发布并归档。

## 2. 审批分级

| 级别 | 范围 | 审核 | 时效 |
|---|---|---|---|
| **A 级 · 必审** | Logo 墙、背景板、展台、官网首页、App 图标、对外画册、联合发布、合作方 Logo 并列 | 品牌负责人 + 业务负责人（涉及法律表述加法务） | 3 个工作日 |
| **B 级 · 抽审** | 海报、单页、活动物料、社媒封面模板、对外 PPT、新表情 / 新动作 | 品牌组 | 1 个工作日 |
| **C 级 · 自检** | 日常社媒图文、内部 PPT、邮件签名、名片（按模板） | 制作人按本 Skill 清单自检，品牌组每月抽查 | 即时 |

AI 生成内容按对应物料级别走同级审核；A 级物料不得仅凭自检发布。

## 3. 文件命名

`NexAI_类别_名称_规格_版本_日期`

示例：`NexAI_海报_Agent冲刺_60x90cm_v2_20261102.pdf`

- 版本：v1、v2…；定稿加 `_final`；
- 日期：8 位 YYYYMMDD；
- 不用空格与特殊符号；
- 源文件（AI / PSD / Figma / PPT）与导出件一起归档入素材库。

## 4. 常见问题

| 问题 | 回答 |
|---|---|
| 可以把 Logo 换成节日色吗？ | 不可以。节日氛围通过背景、插画和小奈的道具表达，Logo 保持官方版本。 |
| 合作方要求 Logo 一样大？ | 联合发布可视觉等高并用竖线分隔，按 A 级审批；常规场合合作方 Logo 小于奈势AI。 |
| 可以自己画小奈新动作吗？ | 可以出内部草图，不可以直接对外发布。新动作 / 新表情按 B 级提交品牌组审核入库。 |
| 英文材料怎么写品牌名？ | 写 NexAI；中文写奈势AI（无空格），首次出现可写「奈势AI（NexAI）」。 |
| 官网怎么写？ | nexai.link，全小写、不加 www；可点击链接写 https://nexai.link。 |
| 缺某个尺寸的素材怎么办？ | 去 <https://brand.nexai.link/downloads.html> 取；仍缺就找品牌组，不要自己放大位图或重画。 |

## 5. 素材授权

- 素材仅限奈势AI 官方及授权合作方使用；合作方使用需提交品牌组审核；
- MiSans 可免费商用，按小米《MiSans 字体知识产权许可协议》使用，不单独售卖、不改名再分发；
- 小奈延展素材（12 表情 + 8 动作）为 v1.2 设计稿，正式商用前由品牌组验收；大幅面印刷建议以 3D 源文件重新渲染。
